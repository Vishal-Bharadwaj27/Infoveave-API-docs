## POST `/api/v10/ngauge/Forms/{id}/get-master-data-options`

**Get Master Data Options**

This endpoint exists to feed governed choices into form fields. Sourcing options centrally keeps entries spelled and coded consistently.

Retrieves a master data options for given column

Tags: `NGague \ Form`
