## POST `/integration/ngauge/{url}/add`

**Add Row**

This endpoint exists so outside websites can submit entries into a form. Public intake works without giving external systems any internal access.

Tags: `NGague \ Form \ Row`

### Parameters

```json
[
  {
    "name": "url",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  }
]
```

```json
{
  "content": {
    "application/json-patch+json": {

        "type": "object"

      "schema": {
        "type": "object"
      }
    },
    "text/json": {
      "schema": {
        "type": "object"

      "schema": {
        "type": "object"
```
