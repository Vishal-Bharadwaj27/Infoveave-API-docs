## POST `/api/v10/ngauge/list-Views/{id}/get-data`

**Get List View Data**

This endpoint exists to serve view data in pages so large lists stay responsive. Paging on the server means the browser never has to download the whole list.

Tags: `NGague \ List \ List View`

[

    "name": "id",
