## GET `/api/v10/ngauge/Forms`

**Get All NGauge Forms**

This endpoint exists so the app can show every form in the tenant. Forms are the structured registers and surveys users fill in, and this is the starting point for managing them.

Tags: `NGague \ Form`

[]
