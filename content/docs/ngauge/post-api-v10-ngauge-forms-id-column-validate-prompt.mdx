## POST `/api/v10/ngauge/Forms/{id}/column/validate-prompt`

**Validate Prompt For AI Column**

This endpoint exists to sanity-check the prompt behind an AI-generated column before it runs. A bad prompt wastes AI calls and fills rows with nonsense, so it is validated first.

Validates the provided prompt intended for use in an AI-generated column within the NGauge form

Tags: `NGague \ Form \ Column`

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
```
