## POST `/api/v10/ngauge/lists/validate`

**Validate List**

This endpoint exists to fail fast on a bad list definition. Validating before save or sync protects every form that depends on the list from inheriting broken configuration.

Tags: `NGague \ List`

```json
[]
```
