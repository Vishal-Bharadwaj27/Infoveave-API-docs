## POST `/api/v10/ngauge/list-Views/{id}/list-archives/download`

**Download List View Archive File**

This endpoint exists to retrieve historical snapshots of a list. Archives matter for audits and for answering what the governed values were on a given date.

Tags: `NGague \ List \ List View`
