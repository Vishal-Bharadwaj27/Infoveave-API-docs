## PATCH `/api/v10/ngauge/Forms/{id}/row/update-cell`

**Update Cell Data**

This endpoint exists for quick single-field fixes with minimal payload. Cell-level writes reduce conflict risk when many people edit the same register.

Tags: `NGague \ Form \ Row`
