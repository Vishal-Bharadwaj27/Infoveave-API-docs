## POST `/api/v10/ngauge/Forms/{id}/download`

**Download NGauge Form Data**

This endpoint exists to produce a spreadsheet of collected entries for offline review and reporting. The export mirrors the live data so shared files stay trustworthy.

Downloads the NGauge form data as an Excel file (.xlsx)

Tags: `NGague \ Form`
