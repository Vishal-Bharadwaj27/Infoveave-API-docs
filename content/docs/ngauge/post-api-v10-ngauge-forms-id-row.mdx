## POST `/api/v10/ngauge/Forms/{id}/row`

**Add Row**

This endpoint exists to submit one new entry with validation applied. Single-row writes are the core data-collection action of the whole service.

Tags: `NGague \ Form \ Row`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
  }
]
```

### Request Body

```json
{
  "content": {
    "application/json-patch+json": {
      "schema": {

      "schema": {
        "$ref": "#/components/schemas/AddRowRequest"
      }
    },
    "text/json": {
      "schema": {
        "$ref": "#/components/schemas/AddRowRequest"
      }

      "schema": {
        "$ref": "#/components/schemas/AddRowRequest"
      }
    }
  },
  "required": true
}
```
