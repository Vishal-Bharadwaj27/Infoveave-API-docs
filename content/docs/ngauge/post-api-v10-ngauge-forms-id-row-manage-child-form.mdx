## POST `/api/v10/ngauge/Forms/{id}/row/manage-child-form`

**Manage Child Form Rows**

This endpoint exists to manage line-item rows that belong to a parent entry in one call. Handling them together prevents orphaned child rows when a parent changes.

Manage adding, editing, and deleting child form rows in a single method

Tags: `NGague \ Form \ Row`
