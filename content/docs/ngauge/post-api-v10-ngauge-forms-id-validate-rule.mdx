## POST `/api/v10/ngauge/Forms/{id}/validate-rule`

**Validate NGauge Form Rule**

This endpoint exists to test a rule before it goes live on the form. Catching broken rules early prevents silent automation failures on real user submissions.

Validates the configured rule for NGauge From actions

Tags: `NGague \ Form`
