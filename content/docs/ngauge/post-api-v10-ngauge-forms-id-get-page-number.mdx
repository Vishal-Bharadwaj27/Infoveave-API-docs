## POST `/api/v10/ngauge/Forms/{id}/get-page-number`

**Get NGauge Form Page Number**

This endpoint exists to find which page a specific record sits on. Deep links and "jump to my entry" flows need this instead of scrolling blindly.

Retrieves the page number for data view

Tags: `NGague \ Form`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
  }
]
```
