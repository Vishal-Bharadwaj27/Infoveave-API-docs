## POST `/api/v10/ngauge/Forms/{id}/views/{viewId}/get-pdf`

**Get NGauge Form Print Pdf**

This endpoint exists to render a record or view as a printable document. PDFs serve signatures, filings and offline records where a web grid will not do.

Get ngauge form print pdf as an Excel file (.xlsx)
