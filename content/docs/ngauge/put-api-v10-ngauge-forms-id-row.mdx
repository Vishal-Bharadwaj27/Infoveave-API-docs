## PUT `/api/v10/ngauge/Forms/{id}/row`

**Update Row**

This endpoint exists to correct a submitted entry while keeping its identity. Editable rows let data stay accurate without deleting history and re-entering.

Tags: `NGague \ Form \ Row`
