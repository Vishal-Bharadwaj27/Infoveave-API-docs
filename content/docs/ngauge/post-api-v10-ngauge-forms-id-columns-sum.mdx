## POST `/api/v10/ngauge/Forms/{id}/columns/sum`

**Get Column Wise Sums**

This endpoint exists to compute sums server-side for numeric columns. Totals for footers and dashboards arrive without shipping every row to the browser.

Calculates and returns the sum of values for each specified column in the NGauge form data

Tags: `NGague \ Form \ Column`
