## POST `/api/v10/ngauge/Forms/{id}/get-data`

**Get NGauge Form Data**

This endpoint exists to serve entries in pages so forms with thousands of rows stay fast. Server-side paging keeps grids responsive on modest devices.

Retrieves a specific page of rows from the NGauge form data

Tags: `NGague \ Form`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
  }
]
```
