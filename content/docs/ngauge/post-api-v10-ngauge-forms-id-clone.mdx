## POST `/api/v10/ngauge/Forms/{id}/clone`

**Clone NGauge Form**

This endpoint exists to spin up a new form from a proven template. Cloning saves rebuilding complex field layouts for every new survey, register or intake.

Tags: `NGague \ Form`
