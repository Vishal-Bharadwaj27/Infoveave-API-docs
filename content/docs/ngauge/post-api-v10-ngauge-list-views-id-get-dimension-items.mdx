## POST `/api/v10/ngauge/list-Views/{id}/get-dimension-items`

**Get Dimension Items for List View**

This endpoint exists to supply the distinct dimension values that drive chart and filter controls. Precomputing them keeps dashboards fast instead of scanning raw rows per interaction.

Tags: `NGague \ List \ List View`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
  }
]
```
