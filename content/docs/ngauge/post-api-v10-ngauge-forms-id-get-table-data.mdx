## POST `/api/v10/ngauge/Forms/{id}/get-table-data`

**Get Table Data **

This endpoint exists to power cascading selects from reference tables. Looking values up live means picklists always reflect current master data.

Retrieves table data options for given table and columns

Tags: `NGague \ Form`

```json
[

    "name": "id",
```
