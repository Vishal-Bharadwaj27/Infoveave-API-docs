## PUT `/api/v10/ngauge/Forms/{id}`

**Update NGauge Form**

This endpoint exists to evolve a form while preserving its collected data. Controlled updates let long-lived registers gain fields without a risky rebuild.

Tags: `NGague \ Form`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
  }
]
```

```json
  "content": {

    }
  },

}
```
