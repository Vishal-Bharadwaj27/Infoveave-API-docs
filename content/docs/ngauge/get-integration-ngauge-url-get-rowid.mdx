## GET `/integration/ngauge/{url}/get/{rowId}`

**Get Row**

This endpoint exists to let embedded integrations fetch a single record by its public URL. It is the read hook for portals that display NGauge data.

Tags: `NGague \ Form \ Row`

### Parameters

```json
[
  {
    "name": "url",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  },
  {
    "name": "rowId",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  }
]
```

    "description": "OK"
