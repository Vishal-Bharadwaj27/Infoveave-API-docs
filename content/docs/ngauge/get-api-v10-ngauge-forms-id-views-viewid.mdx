## GET `/api/v10/ngauge/Forms/{id}/views/{viewId}`

**Get View By Id**

This endpoint exists to load a single view definition for rendering or editing. It separates view configuration from the rows it displays.

Tags: `NGague \ Form \ View`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
  },
  {
    "name": "viewId",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
  }
]
```
