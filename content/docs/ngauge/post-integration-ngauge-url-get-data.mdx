## POST `/integration/ngauge/{url}/get-data`

**Get NGauge Form Data**

This endpoint exists so third-party sites can read form data through a stable public URL. External consumers never need internal form IDs, which keeps integrations working across renames and moves.

Retrieves a specific page of rows from the NGauge form data

Tags: `NGague \ Form`

### Parameters

```json
[
  {
    "name": "url",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  }
]
```
