## PATCH `/api/v10/ngauge/Forms/{id}/row/delete`

**Delete Row**

This endpoint exists to remove an entry that should never have existed. Row-level deletion keeps registers clean without touching the form definition.

Tags: `NGague \ Form \ Row`
