## DELETE `/api/v10/ngauge/Forms/{id}/views/{viewId}`

**Delete View**

This endpoint exists to remove views nobody needs anymore. Pruning keeps the view list navigable as teams and questions change.

Tags: `NGague \ Form \ View`

```json
[

    "schema": {

  {
    "name": "viewId",
    "in": "path",
    "required": true,

```
