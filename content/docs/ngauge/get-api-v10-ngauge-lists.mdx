## GET `/api/v10/ngauge/lists`

**Get All Lists**

This endpoint exists so configuration screens can show every reusable value list in the tenant. Lists are the shared dropdowns and masters that keep data entry consistent across forms.

Tags: `NGague \ List`

[]
