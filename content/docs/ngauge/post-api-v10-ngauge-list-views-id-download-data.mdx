## POST `/api/v10/ngauge/list-Views/{id}/download-data`

**Download List View Data**

This endpoint exists to dump a view to a file for offline review or sharing. Exporting from the saved view guarantees the file matches exactly what the user sees on screen.

Tags: `NGague \ List \ List View`

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
  }
]
```
