## PATCH `/api/v10/ngauge/Forms/{id}/column/delete`

**Delete Column**

This endpoint exists to drop a field that should no longer be collected. Explicit deletion keeps schemas honest instead of hiding dead columns.

Tags: `NGague \ Form \ Column`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
  }
]
```
