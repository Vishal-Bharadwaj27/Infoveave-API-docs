## PUT `/integration/ngauge/{url}/update/{rowId}`

**Update Row**

This endpoint exists to let integrated systems correct entries they own. Scoped updates keep embedded portals useful after the first submission.

Tags: `NGague \ Form \ Row`

  {

      "type": "string"

  {
    "name": "rowId",

    "required": true,
    "schema": {
      "type": "string"
    }
  }
]
