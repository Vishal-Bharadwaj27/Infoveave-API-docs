## DELETE `/integration/ngauge/{url}/delete/{rowId}`

**Delete Row**

This endpoint exists to let integrations retract entries through the same public URL scheme. Full lifecycle support means portals never strand bad data.

Tags: `NGague \ Form \ Row`

### Parameters

```json
[
  {
    "name": "url",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  },
  {
    "name": "rowId",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  }
]
```

### Responses

{
  "200": {
    "description": "OK"
