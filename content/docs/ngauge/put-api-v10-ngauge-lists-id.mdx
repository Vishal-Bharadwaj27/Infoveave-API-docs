## PUT `/api/v10/ngauge/lists/{id}`

**Update List**

This endpoint exists to change a list definition while every form using it keeps working. Central edits here propagate to all consumers instead of being copy-pasted per form.

Tags: `NGague \ List`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
  }
]
```
