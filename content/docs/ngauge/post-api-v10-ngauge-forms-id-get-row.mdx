## POST `/api/v10/ngauge/Forms/{id}/get-row`

**Get Row**

This endpoint exists to load one record for viewing or editing. Targeted reads avoid pulling whole pages when only one entry matters.

Tags: `NGague \ Form \ Row`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "pattern": "^-?(?:0|[1-9]\\d*)$",
      "type": [
        "integer",
        "string"
      ],
      "format": "int64"
    }
  }
]
```
