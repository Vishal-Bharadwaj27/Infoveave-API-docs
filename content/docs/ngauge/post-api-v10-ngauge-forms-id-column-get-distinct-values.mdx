## POST `/api/v10/ngauge/Forms/{id}/column/get-distinct-values`

**Get Distinct Values For Column**

This endpoint exists to power filters and facets with the actual values present. Distinct lists keep filter controls truthful without scanning rows on the client.

Retrieves a list of all distinct (unique) values present in a specified column within the NGauge form data

Tags: `NGague \ Form \ Column`

[
