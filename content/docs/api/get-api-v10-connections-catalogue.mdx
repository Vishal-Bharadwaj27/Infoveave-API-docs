## GET `/api/v10/Connections/catalogue`

**Get connection provider catalogue**

This endpoint exists so that "new connection" screens can show which providers are available and what settings each one requires. It exposes provider shapes and metadata only, never secrets, letting the UI build the right form for each provider.

Tags: `Connections`
