## POST `/api/v10/Connections/connections/{id}/restore`

**Restore a deleted connection**

This endpoint exists so a deleted connection can be brought back without re-entering credentials and settings. It is the safety net for the soft-delete behaviour above.

Tags: `Connections`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string",
      "format": "uuid"
    }
  },
  {
    "name": "If-Match",
    "in": "header",
    "schema": {
      "type": "string"
    }
  }
]
```
