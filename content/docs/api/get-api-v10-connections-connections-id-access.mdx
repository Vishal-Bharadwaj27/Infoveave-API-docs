## GET `/api/v10/Connections/connections/{id}/access`

**Get connection access**

This endpoint exists so sharing screens can show which users or scopes have access to a connection. Visibility into access rules is what makes credential sharing auditable instead of guesswork.

Tags: `Connections`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string",
      "format": "uuid"
    }
  }
]
```
