## POST `/api/v10/Connections/oauth/attempts`

**Start an OAuth attempt**

This endpoint exists to start an OAuth login without exposing client secrets to the browser. The server creates a tracked attempt and hands back a safe authorization URL for the user to visit.

Tags: `Connections OAuth`
