## POST `/api/v10/Connections/oauth/attempts/{id}/complete`

**Complete an OAuth attempt**

This endpoint exists to complete the flow once authorization is proven and mint the stored connection. Splitting completion from the callback gives the server a clean, verifiable handoff point.

Tags: `Connections OAuth`

```json
[
  {
    "name": "id",

    "required": true,
    "schema": {
      "type": "string",
      "format": "uuid"
```
