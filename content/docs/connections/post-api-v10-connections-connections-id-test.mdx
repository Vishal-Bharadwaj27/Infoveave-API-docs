## POST `/api/v10/Connections/connections/{id}/test`

**Test a connection**

This endpoint exists to probe the data source with the stored credentials before anything depends on them. Testing early catches typos, expired passwords and firewall issues before scheduled jobs fail at night.

Tags: `Connections`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string",
      "format": "uuid"
    }
  }
]
```
