<Accordion title="ConnectionAuthMode">
How the connection signs in.

| Value | Name |
| --- | --- |
| 0 | None |
| 1 | ConnectionString |
| 2 | ApiKey |
| 3 | BearerToken |
| 4 | Basic |
| 5 | OAuthClientCredentials |
| 6 | OAuthAuthorizationCode |
| 7 | CustomHeaders |
| 8 | ServiceAccountJson |
| 9 | AwsCredentials |
| 10 | AwsRoleAssumption |
| 11 | AzureServicePrincipal |
| 12 | AzureManagedIdentity |
| 13 | GcpServiceAccount |

Each provider supports only some auth modes, and each mode needs particular secrets. For example `ConnectionString` needs `connectionString`, `ApiKey` needs `apiKey`, `BearerToken` needs `accessToken` or `bearerToken`, `Basic` needs `username` and `password`, and `OAuthClientCredentials` needs `clientSecret` (plus a public `clientId`).
