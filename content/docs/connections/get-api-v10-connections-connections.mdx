## GET `/api/v10/Connections/connections`

**List accessible connections**

This endpoint exists so dashboards and pickers can show exactly the connections the current user is allowed to see. Filtering happens server-side, which is what keeps one tenant from ever seeing another tenant's data sources.

Tags: `Connections`
