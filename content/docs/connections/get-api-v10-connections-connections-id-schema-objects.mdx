## GET `/api/v10/Connections/connections/{id}/schema/objects`

**List schema objects**

This endpoint exists so query builders and mapping screens can list the tables or objects available through a connection. It lets users discover data without writing raw queries first.

Tags: `Connections`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string",
      "format": "uuid"
    }
  }
]
```

### Responses

```json
{
  "200": {
    "description": "OK",
    "content": {
      "text/plain": {
        "schema": {
          "$ref": "#/components/schemas/ConnectionObjectListingResult"
        }
      },
      "application/json": {
        "schema": {
          "$ref": "#/components/schemas/ConnectionObjectListingResult"
        }
      },
      "text/json": {
        "schema": {
          "$ref": "#/components/schemas/ConnectionObjectListingResult"
        }
      }
    }
  },
  "400": {
    "description": "Bad Request",
    "content": {
      "application/problem+json": {
        "schema": {
          "$ref": "#/components/schemas/ProblemDetails"
        }
      }
    }
  }
}
```
