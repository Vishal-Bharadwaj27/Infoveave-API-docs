## PUT `/api/v10/Connections/connections/{id}`

**Completely replace a connection**

This endpoint exists to apply full, validated replacements rather than ambiguous partial patches. Replacing the whole record keeps the stored configuration predictable and avoids leftover stale settings.

Tags: `Connections`

### Parameters

```json
[
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string",
      "format": "uuid"
    }
  },
  {
    "name": "If-Match",
    "in": "header",
    "schema": {
      "type": "string"
    }
  }
]
```
