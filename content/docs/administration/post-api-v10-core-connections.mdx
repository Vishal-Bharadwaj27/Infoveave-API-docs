## POST `/api/v10/core/connections`

**Create Connection**

Creates a tenant-scoped core connection in one step. Send `Name`, `Configuration`, `ConnectionType` and `CredentialType` (all required — `ConnectionCreateRequestValidator`). The handler persists the connection, then returns the schema with secrets redacted (`GetRedactedConnectionConfig`). Use the returned `Id` for every follow-up call.

Workflow: create → `GET {id}/tables` to discover tables → `POST {id}/get-columns` for columns → `POST {id}/table/get-sample-data` to preview → `POST {id}/execute-query` to run queries. OAuth types go through `GET oauth/authorize` then `POST {connectionType}/authorize-callback`; re-check with `POST oauth/{id}/validate-credentials`. Pin a working connection with `PATCH {id}/set-as-default`.
