title: Infoveave API
description: Reference documentation for the Infoveave Connections, NGauge, Data Governance, Data Graph and Data Quality services.
---

Pick a service from the sidebar:

- **Connections**: register, share, test and resolve data-source connections.
- **NGauge**: structured data collection with forms, lists and external integrations.
- **Data Governance**: catalogue, lineage, tags and governance templates.
- **Data Graph**: cache, OData, performance metrics and monitoring.
- **Data Quality**: test suites and data introspection.
