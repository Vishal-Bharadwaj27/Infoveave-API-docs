## GET `/api/v10/data-governance/Catalogue/{entityType}/{id}/linked-entities`

**Get Linked Entities**

Retrieves all entities that are linked or associated with the specified item

```json
[

    "name": "entityType",

  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  }
]
```
