## POST `/api/v10/data-governance/Catalogue/{entityType}/{id}/ai/description`

**Update AI Description**

Generate an updated description for the provided entity using AI

```json
[
  {
    "name": "entityType",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  },
  {
    "name": "id",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  }
]
```
