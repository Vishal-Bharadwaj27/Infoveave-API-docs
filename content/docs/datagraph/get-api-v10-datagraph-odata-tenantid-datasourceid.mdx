## GET `/api/v10/datagraph/odata/{tenantId}/{datasourceId}`

**Get OData Service Document**

Returns a service document listing all available **entity sets (tables)** that can be queried for this datasource.

**Response Includes:**
- Entity set names and their direct access URLs
- Tenant and datasource context information

**Use Cases:**
- Discovering available tables in a datasource
- Client applications listing accessible entities
- API navigation and discoverability

**Example Request:**
`GET /odata/tenant1/datasource1/`

**Example Response:**
```json
{ "entitySets": [{ "name": "Products", "url": "..." }] }
```
