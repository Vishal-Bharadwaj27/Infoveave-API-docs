## GET `/api/v10/datagraph/odata/{tenantId}/{datasourceId}/$metadata`

**Get OData Metadata Document**

Returns the complete OData CSDL (Conceptual Schema Definition Language) metadata document in XML format.

**Includes:**
- Entity Types: All available tables with properties and data types
- Properties: Column definitions with type information and nullability
- Navigation Properties: Relationships between entities (one-to-many, many-to-one)
- Associations: Relationship definitions with multiplicity information

**Use Cases:**
- OData client tools discover the data model
- API documentation generators parse for UI
- Query builders reference this for validation

**Example:** `GET /odata/tenant1/datasource1/$metadata`

Tags: `OData`

### Parameters

```json
[
  {
    "name": "tenantId",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  },
  {
    "name": "datasourceId",
    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  }
]
```
