## GET `/api/v10/datagraph/performance/relationships/{sourceTable}/{relationshipName}/{targetTable}`

**Get Relationship Performance Metrics**

Retrieve detailed performance metrics for a specific relationship query including query count, cache statistics, and execution times.

    "in": "path",

  {

    "in": "path",
    "required": true,
    "schema": {
      "type": "string"
    }
  }
]
