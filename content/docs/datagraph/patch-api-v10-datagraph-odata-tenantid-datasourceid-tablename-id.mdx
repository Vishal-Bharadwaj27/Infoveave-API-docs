## PATCH `/api/v10/datagraph/odata/{tenantId}/{datasourceId}/{tableName}({id})`

**Update Existing Record**

**Updates an existing entity** with partial or complete data using true PATCH semantics.

**Process:**
1. Locates record by ID
2. Validates provided fields only (not entire record)
3. Sanitizes input data
4. Updates specified fields in database
5. Invalidates table cache
6. Returns 200 OK with complete updated record

**Request Body:** JSON with fields to update (send only changed fields)
```json
{ "Price": 1199.99, "Stock": 45 }
```

**Key Behavior:** Only specified fields updated; others unchanged

**ID Format:** String IDs in single quotes - `Orders('ORD-123')`

**Response:**
- **200 OK**: Complete updated record with all fields
- **400 Bad Request**: Validation error
- **404 Not Found**: Record doesn't exist
- **500 Internal Server Error**: Database error

Tags: `OData`
