## DELETE `/api/v10/datagraph/odata/{tenantId}/{datasourceId}/{tableName}({id})`

**Delete Record**

**Deletes an existing entity** from the table.

**Process:**
1. Verifies record exists by ID
2. Deletes record from database
3. Invalidates table cache
4. Returns 204 No Content (no body)

**ID Format:** String IDs in single quotes
- `Products('SKU-001')`
- Numeric IDs without quotes: `Products(12345)`

**Response:**
- **204 No Content**: Success, no response body
- **404 Not Found**: Record doesn't exist
- **500 Internal Server Error**: Database error

**Example:**
`DELETE /odata/tenant1/datasource1/Products(12345)`
