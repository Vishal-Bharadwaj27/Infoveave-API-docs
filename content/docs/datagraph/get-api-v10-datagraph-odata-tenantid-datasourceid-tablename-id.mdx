## GET `/api/v10/datagraph/odata/{tenantId}/{datasourceId}/{tableName}({id})`

**Query Single Record by ID**

Retrieves a **single record by its primary key** identifier.

**Returns:** Single JSON object (not an array)

**Supported Query Parameters:**
- **$select**: Column projection - `Products(123)?$select=Name,Price`
- **$expand**: Load relationships - `Products(123)?$expand=Orders`

**String ID Format:** Enclose in single quotes
- `Products('SKU-001')`
- `Orders('ORD-2025-001')`

**Numeric ID Format:** Use directly
- `Products(12345)`

**Examples:**
`GET /odata/tenant1/datasource1/Products(123)`
`GET /odata/tenant1/datasource1/Products('ABC')?$expand=Orders`

**Response:** `200 OK` with entity object | `404 Not Found` if record doesn't exist
