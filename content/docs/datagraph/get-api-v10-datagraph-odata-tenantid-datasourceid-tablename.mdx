## GET `/api/v10/datagraph/odata/{tenantId}/{datasourceId}/{tableName}`

**Query Collection with OData Parameters**

Queries a table with **comprehensive OData support** for filtering, sorting, pagination, and relationship expansion.

**Query Parameters:**
- **$filter**: `Age gt 18 and Status eq 'Active'` - Comparison (eq, ne, gt, lt, ge, le) + logical (and, or, not)
- **$select**: `Name,Email,Phone` - Project columns; relationships always included
- **$orderby**: `Name asc, Date desc` - Sort by multiple columns with direction
- **$expand**: `Orders` or `Orders($expand=Items)` - Load related entities with batch optimization
- **$skip**: `20` - Offset for pagination
- **$top**: `10` - Limit records (max 1000)
- **$count**: `true` - Include total in `@odata.count`

**Security:**
- SQL injection prevention via pattern detection
- Column-level access control
- Parameterized SQL execution

**Performance:**
- Query result caching (5-minute TTL, auto-invalidated on mutations)
- Relationship batching (60-70× fewer queries)
- GZip compression (40-60% bandwidth reduction)

**Examples:**
`GET /odata/tenant1/datasource1/Products?$filter=Price gt 100`
`GET /odata/tenant1/datasource1/Orders?$expand=Items&$count=true`

**Response:** Returns `{ "value": [...], "@odata.count": N }` on success
